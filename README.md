## The pitfalls that eat cash back before it lands

A few specific things kill Expedia cash back more often than anything else:

- **Using a coupon code not displayed on TopCashback.** The merchant page is explicit about this: any external coupon code applied at checkout can invalidate the cash back tracking. If there's a promo code on the TopCashback Expedia page, use that one. If the only code available is from a random coupon site, decide which is worth more — the code discount or the cash back. Usually the cash back wins on bigger bookings.
- **Changing the region on Expedia mid-session.** Switching from Expedia.com to Expedia.co.uk or another regional version after clicking through breaks the tracking.
- **Booking through a different browser or device.** The tracking cookie is browser-specific. If you click through on a laptop and complete the booking on a phone, the cash back won't track.
- **Using ad blockers or privacy extensions aggressively.** Some ad blockers strip tracking cookies. If cash back isn't tracking and everything else is right, this is the next thing to check.
- **AdBlockers / incognito mode.** Same issue — incognito sessions often clear cookies before the booking completes.
- **Exceeding the booking in cash back.** Cash back can't exceed the purchase amount. Not a real concern on flights, but on a deeply discounted hotel it can cap the payout.
- **Forgetting to start with an empty cart.** Already-covered but worth repeating.
